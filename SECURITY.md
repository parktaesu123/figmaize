# Security

Only the current alpha is maintained. The bridge is local, authenticated and exposes an explicit command allowlist. It is not a hosted multi-user service.

Do not publish connection codes, cookies, private captures or private Figma URLs in issues. Private vulnerability reporting has not yet been enabled for this repository. Until a private channel is available, open only a non-sensitive request for a private contact channel; do not include exploit details or credentials.

A lost Figma result is deliberately treated as unresolved. Inspect the canvas before recovery; restarting a server is not evidence that a mutation never ran.
