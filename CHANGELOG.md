# Changelog

## 0.3.0-alpha.1

- Figma URL input, page discovery and selection, viewport/interaction limits, collection list, progress, cancellation and resume.
- Shared authenticated site service used by both the plugin and MCP. Detached workers checkpoint results and keep unresolved imports explicit.
- Optional site pages, exact-match component instances, selector-matched variants and conservative prototype connections.
- Stable DOM selectors; video first-frame readiness; selected-page navigation restrictions.
- `figmaize setup`, `doctor`, `start`, `mcp`, `capture`, `import` and `compact` CLI; user data directory; pinned Playwright and lockfile.
- Development plugin packaging, CI/browser tests, release artifacts and source installation documentation.

This is an alpha. npm registry publication and Figma Community approval are separate account-dependent steps; neither is implied by this version.

## 0.2.0

- Local authenticated bridge, stdio MCP, Figma importer and Chrome extension.
- Editable semantic controls and measured Auto Layout.
- Website collection manifests, durable import journals and compact nested state layouts.
- MIT open-source repository and separation of private Toss capture data.
