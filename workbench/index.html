GETTING STARTED

화면에서 피그마까지.

  1. Chrome 확장 설치

    chrome://extensions에서 개발자 모드를 켜고 ‘압축해제된 확장 프로그램 로드’로 프로젝트의 extension 폴더를 선택하세요.

  2. 원하는 화면 수집

    서비스를 열고 확장의 ‘현재 화면 수집하기’를 누르세요. 저장한 JSON을 이 작업실에서 확인할 수 있습니다.

  3. 피그마 플러그인 설치

    Figma 데스크톱의 Plugins → Development → Import plugin from manifest에서 figma/manifest.json을 선택하세요.

  4. 편집 가능한 레이어 생성

    플러그인을 실행하고 저장한 JSON을 선택하세요. 원본 이미지와 편집 가능한 화면이 나란히 생성됩니다.

앱 스크린샷은 이미지를 올린 뒤 텍스트·도형·이미지 분리 도구로 영역을 직접 지정하세요. 자동 OCR·자동 컴포넌트 변환은 이 버전에 포함되지 않습니다.
